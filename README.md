🐫 CamoGate
===========

پروژه دانلود از طریق اینترنت داخلی بر بستر گیت هاب GitHub Camo

* * *

📖 معرفی
--------

پروژه CamoGate یک ابزار است که به شما امکان دانلود با اینترنت داخلی و محدود رو میدهد

**✨ نحوه کار پروژه:**

لینک فایل حجیم خود را به ربات تلگرام یا نسخه وب بدهید. Cloudflare Worker فایل را دانلود کرده، به تکه‌های ۵۰۰ کیلوبایتی تقسیم می‌کند و یک فایل `README.md` بسیار کم‌حجم (چند کیلوبایت) حاوی لینک تمام تکه‌ها به شما تحویل می‌دهد.

کافی است این فایل `README.md` را در یک ریپازیتوری گیت‌هاب قرار دهید. سپس اسکریپت پایتون را اجرا کنید؛ اسکریپت با خواندن فایل `README.md`، تمام تکه‌ها را از طریق گیت‌هاب دانلود کرده و پس از ادغام، فایل اصلی را بازسازی می‌کند — همه اینها بدون نیاز به اینترنت پرسرعت و در بستر محدود ملی.

**✨ ویژگی‌ها:**

*   دانلود فایل‌ها از طریق محدودیت‌های شبکه
*   بررسی صحت فایل با هش
*   پشتیبانی از فایل‌های تا 200 مگابایت



🚀 راه‌اندازی
-------------------------

### دیپلوی روی Cloudflare Workers

1.  وارد [Cloudflare Dashboard](https://dash.cloudflare.com) شوید
2.  به بخش **Workers & Pages** بروید
3.  روی **Create application** → **Create Worker** کلیک کنید
4.  نام worker را انتخاب کنید (مثلاً `camo-bot`)
5.  کد فایل `worker.js` را در ادیتور قرار دهید
6.  توکن ربات خود را در خط اول جایگزین کنید
7.  روی **Save and Deploy** کلیک کنید


### ساخت ربات در تلگرام

درصورتی که بخواهید از ربات تلگرام هم در کنار نسخه وب استفاده کنید میتوانید این مراحل را انجام دهید.

1.  به [@BotFather](https://t.me/BotFather) در تلگرام بروید
2.  دستور `/newbot` را بزنید
3.  نام و یوزرنیم ربات را انتخاب کنید
4.  توکن دریافتی را کپی کنید
5.  توکن را با نام `TELEGRAM_TOKEN` در بخش `Variables and Secrets` در قسمت `setting` مربوط به ورکر کلود فلر وارد کنید.
6.  ربات تلگرامی خودتون رو به وب هوک ورکر وصل کنید با این دستور ``
curl -X POST "https://api.telegram.org/bot[TOKEN]/setWebhook?url=https://[YOUR_WORKER].workers.dev/webhook"
``
7. **✅ ربات شما آماده است!** حالا در تلگرام به ربات `/start` بزنید.

📥 نحوه استفاده
-----------------------

1.  لینک مستقیم فایل خود را به نسخه وب یا ربات تلگرام بفرستید (مثلاً `https://example.com/file.zip`)
2.  سیستم فایل را دانلود کرده و تکه‌تکه می‌کند
3.  فایل `README.md` آماده می‌شود
4.  این README را در یک ریپازیتوری گیت‌هاب آپلود کنید

**💡 نکته:** سیستم اطلاعات زیر را در README قرار می‌دهد:

*   نام فایل اصلی
*   حجم فایل
*   هش MD5 برای تأیید صحت
*   تکه‌های رمزنگاری شده به صورت تصاویر SVG

🐍 بازسازی فایل با اسکریپت پایتون
---------------------------------

### پیش‌نیازها

*   Python 3.7 یا بالاتر
*   کتابخانه requests

```code
pip install requests
```

### نحوه استفاده

\# روش 1: لینک مستقیم README


```
python github_camo_downloader_final.py "https://raw.githubusercontent.com/USER/REPO/main/README.md"
```
    
# روش 2: بدون آرگومان (ورودی تعاملی)

```aiignore
python github_camo_downloader_final.py
```

🔧 عیب‌یابی
-----------

**خطا: "هیچ تگ متنی در SVG یافت نشد"**  
احتمالاً لینک‌های Camo منقضی شده‌اند. دوباره از ربات بخواهید README جدید بسازد.

**خطا: "README.md در ریپازیتوری پیدا نشد"**  
اطمینان حاصل کنید که README در ریپازیتوری وجود دارد یا از لینک مستقیم استفاده کنید.

**ربات پاسخ نمی‌دهد**  
بررسی کنید Webhook به درستی تنظیم شده باشد و لاگ‌های Cloudflare Worker را بررسی کنید.
