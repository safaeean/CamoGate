# 🐫 CamoGate - Telegram Bot for Downloading via GitHub Camo

[فارسی](#فارسی) | [English](#english)

## فارسی
ربات تلگرامی که با استفاده از زیرساخت GitHub Camo، فایل‌ها را دانلود کرده و به صورت تکه‌تکه در README ذخیره می‌کند.

### ویژگی‌ها
- 🚀 دانلود فایل‌ها از طریق اینترنت ملی ایران
- 🔒 ذخیره فایل به صورت رمزنگاری شده در README گیت‌هاب
- ✅ بررسی صحت فایل با MD5
- 📦 بازسازی خودکار فایل با اسکریپت پایتون
